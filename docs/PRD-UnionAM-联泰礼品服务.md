# UnionAM 联泰礼品与 3D 打印服务平台 PRD

**版本**：V0.1（初稿）
**日期**：2026-07-15
**产品形态**：UnionAM 工具站新增业务应用，员工端为 `unionam.com/gift`，后台管理端为 `ops.unionam.com`
**目标用户**：上海联泰科技股份有限公司内部员工
**产品状态**：待业务、IT、生产与合规评审

## 1. 产品概述

联泰礼品与 3D 打印服务平台是面向联泰科技内部员工的统一业务打印申请平台。它不仅服务于“给客户送什么礼品”的需求，也承接展会样品、客户打样件、销售演示件和其他用于公司业务的 3D 打印需求。

员工通过企业微信扫码登录后，可以：

1. 根据客户行业、品牌调性、拜访场景和礼赠目的，从模型库选择独一无二的 3D 打印礼品；
2. 上传图片、填写客户特征和礼品使用场景，由 3D 模型生成工具生成可打印的专属礼品；
3. 提交展会展示样品、客户样件、销售演示件等业务打印申请；
4. 查看模型预览、打印可行性检查结果、申请进度和领取信息。

平台将原本分散在聊天、表格、临时沟通中的打印需求统一沉淀，帮助公司把客户礼赠做得更有差异化，同时提升 3D 打印服务的业务承接量和生产资源利用率。后台为礼品管理员、模型审核人员和生产人员提供模型管理、生成任务审核、业务申请、打印排产、资产复用和数据统计能力。

### 1.1 产品目标

- 建立内部员工可自助使用的 3D 打印礼品申请入口。
- 将礼品模型选择、个性化生成、打印申请和生产交付串成完整闭环。
- 统一承接客户礼赠、展会样品、客户样件、销售演示件和其他公司业务打印需求。
- 让客户礼品更贴合客户调性、业务场景和品牌特征，形成独一无二的 3D 打印体验。
- 将每次展会和业务活动产生的模型、样件和打印记录沉淀为可复用的企业数字资产。
- 在保证知识产权、客户隐私和生产安全的前提下，降低 3D 礼品定制门槛。
- 沉淀可复用的礼品模型库、生成记录和生产数据，为后续企业礼品运营提供基础。

### 1.2 非目标

- V1 不面向外部公众开放，不接入公开注册。
- V1 不做开放式模型社区，不允许员工直接公开发布模型。
- V1 不承诺所有 AI 生成模型无需人工检查即可打印。
- V1 暂不强制接入打印机硬件，生产人员可下载模型后使用现有生产流程打印。

## 2. 用户与角色

| 角色 | 主要权限 |
| --- | --- |
| 内部员工 | 企业微信登录、浏览礼品与业务样件、提交生成任务、提交客户礼品/业务打印申请、查看本人申请 |
| 礼品管理员 | 管理模型、分类、上下架、规格、库存/产能限制、订单规则 |

| 系统管理员 | 企业微信配置、权限管理、数据保留策略、操作审计和系统配置 |

## 3. 核心业务流程

### 3.1 员工登录

1. 员工打开 `unionam.com/gift`。
2. 点击“企业微信扫码登录”。
3. 通过企业微信 OAuth/扫码流程完成身份认证。
4. 服务端校验员工是否属于联泰企业、账号是否在职、是否具备使用权限。
5. 首次登录自动创建员工档案；再次登录直接进入礼品首页。
6. 登录态使用安全 HttpOnly Cookie 保存，登录状态与首页、报价工具、格式转换工具的通栏保持一致。

登录失败时需明确提示：二维码过期、非本企业成员、账号已停用、无权限或系统异常。

### 3.2 现有礼品模型下单

员工浏览模型库 → 查看模型详情 → 选择规格/颜色/数量/领取方式 → 确认订单 → 提交 → 管理员审核 → 生产 → 员工领取或配送 → 完成。

### 3.3 AI 生成模型下单

员工填写需求和上传素材 → 系统进行内容与文件校验 → AI 生成多个候选模型 → 员工选择候选并调整需求 → 自动进行可打印性检查 → 需要时进入人工审核 → 选择规格并下单 → 生产交付。

“生成完成”与“可打印”必须是两个独立状态。模型检查不通过时，系统必须显示原因和修改建议，不能直接进入生产队列。

### 3.4 展会与业务样件申请

员工填写业务使用场景、模型来源、数量、期望完成时间和用途说明，可关联已有模型或提交新模型/样件需求。申请进入统一审核、排产和交付流程，完成后的模型文件、打印参数和生产记录可沉淀到企业模型库，供后续展会或客户项目复用。

## 4. 员工端功能需求

### 4.1 礼品首页

页面复用 UnionAM 现有视觉规范、顶部通栏、Logo 和多语言切换组件。

内容包括：

- 联泰礼品服务介绍和使用规则；
- “从礼品库选择”和“AI 生成专属礼品”两个主入口；
- 推荐礼品、热门礼品、最新上架礼品；
- 员工当前订单状态；
- 月度/年度可用额度或次数（如果业务启用）；
- 数据安全和内部使用提示。

### 4.2 礼品模型库

支持：

- 分类：客户礼赠、企业文化、展会样品、客户打样件、销售演示件、节日礼品、桌面摆件、其他；
- 关键词搜索、标签筛选、按热门/最新排序；
- 模型卡片展示缩略图、名称、适用场景、预计打印时间、材料和尺寸范围；
- 模型详情页展示 3D 预览、图片、规格、注意事项、可选颜色/材料、可打印状态；
- 支持模型个性化字段，例如姓名、部门、日期、客户名称或简单文字；
- 只有“已上架且可打印”的模型可以下单。

### 4.3 AI 3D 模型生成

#### 输入方式

- 上传 1～5 张参考图片；
- 文本描述：物体特征、风格、尺寸、结构要求；
- 礼品场景：客户拜访、展会纪念、员工生日、节日活动等；
- 个性化信息：文字、Logo、编号等；
- 打印偏好：材料、颜色、预计尺寸、打印技术。

#### 生成流程

1. 显示输入要求、禁止内容和素材版权提示。
2. 对图片进行格式、大小、病毒和敏感内容检查。
3. 生成任务进入队列，前端显示排队、生成中、成功、失败状态。
4. 默认生成 2～4 个候选模型或模型方案。
5. 展示模型 3D 预览、缩略图、生成描述和版本信息。
6. 员工可选择候选、修改文字需求并重新生成。
7. 系统自动检查模型格式、单位、比例、法向、破面、非流形、封闭性、最小壁厚和明显悬空结构。
8. 检查通过后显示“建议打印”；风险项显示“需人工审核”。

#### 生成失败与限制

- 输入不清晰时提示补充图片或描述；
- 超出模型能力范围时提示暂不支持的结构类型；
- 单个员工的生成次数、文件大小和并发任务数可配置；
- 失败任务允许重试，但需保留失败原因和任务日志；
- 不允许生成违法、侵权、攻击性或明显不适合生产的内容。

### 4.4 下单

订单信息包括：

- 礼品模型及版本；
- 规格、数量、材料、颜色、打印技术；
- 预计打印时间和预计完成时间；
- 领取方式：办公地点自取，后续可扩展内部配送；
- 领取人信息和联系电话；
- 订单用途和备注；
- 业务使用场景、模型来源和期望完成时间；
- 是否需要礼品包装或附卡。

V1 默认不接入在线支付，订单提交后进入内部审核/生产流程。若后续需要成本核算，可增加预算归属部门、项目号或内部结算字段，不应直接复用公开报价工具的支付逻辑。

提交前必须明确展示：模型可能需要人工调整、预计时间为估算值、生成素材的使用范围、取消规则和领取规则。

### 4.5 我的订单

员工可以查看：

- 订单编号、模型缩略图、规格和数量；
- 当前状态、状态更新时间和预计完成时间；
- 审核不通过原因、生产异常说明；
- 领取地点、领取码或配送信息；
- 取消订单入口（仅在未进入生产前开放）。

订单状态建议为：

`草稿 → 待审核 → 已批准 → 排产中 → 打印中 → 后处理 → 待领取/配送中 → 已完成`

异常状态：`已驳回、已取消、生产失败、待补充信息`。

## 5. 后台管理功能

后台统一部署在 `ops.unionam.com`，不在员工端页面暴露管理入口。访问后台时必须先完成企业微信身份认证，再根据管理员、模型审核员、生产人员等角色授予对应权限。

### 5.1 模型库管理

- 上传 STL、OBJ、3MF 等模型文件及预览图；
- 维护名称、描述、分类、标签、适用场景、版权归属；
- 维护尺寸范围、材料、颜色、打印技术、预计时间；
- 模型版本管理和上下架；
- 设为推荐、热门或仅指定部门可见；
- 记录上传人、审核人、更新时间和操作日志。

### 5.2 AI 生成审核

- 查看员工输入素材、生成结果和自动检查报告；
- 标记为可打印、需修改、禁止生产；
- 填写驳回原因和修改建议；
- 将质量较好的模型转入正式礼品库；
- 支持审核记录追溯，禁止无日志覆盖原始版本。

### 5.3 订单与生产管理

- 按申请类型、订单状态、员工、部门、模型、用途和时间筛选；
- 批量批准、排产、更新状态；
- 下载模型和生产备注；
- 记录打印机、材料批次、操作人员、失败原因；
- 统计客户礼赠、展会样品、业务样件等不同类型的打印需求和产能占用；
- 设置领取地点、领取码和完成确认；
- 订单导出需受管理员权限控制并记录审计日志。

### 5.4 业务配置

- 员工访问范围和部门白名单；
- 单人生成次数、订单数量、并发任务数；
- 每种礼品的产能、库存和每日接单上限；
- 是否需要人工审核；
- 是否允许取消、是否允许重复下单；
- 领取地点、工作时间、通知模板。

## 6. 权限与安全要求

### 6.1 身份安全

- 只允许企业微信认证成功且在职的员工使用员工端；
- 不允许通过前端传入员工姓名、部门来伪造身份；
- 所有订单、素材和模型下载接口必须在服务端校验归属权限；
- 管理后台必须进行角色权限控制，不能仅依赖隐藏前端菜单。

### 6.2 文件与数据安全

- 图片、客户特征、客户 Logo 等内容可能包含商业机密或个人信息，应按敏感数据处理；
- AI 生成所需素材上传前，必须提示数据用途、保存周期和处理范围；
- 默认使用公司可控的存储和模型服务，不将内部素材直接发送给未审批的公共 AI 服务；
- 原始图片、生成任务和模型文件使用私有存储、签名 URL 和访问有效期；
- 文件下载、预览、生成、删除和导出全部记录审计日志；
- 设置数据保留策略，建议生成中间文件默认保留 30～90 天，订单关联文件按公司制度保留；
- 退出登录、离职停用和权限撤销应立即失效服务端会话。

### 6.3 打印安全

- AI 模型必须经过自动检查；
- 自动检查不通过或存在高风险结构时必须人工审核；
- 生产人员只能下载已批准版本；
- 订单模型版本一旦进入生产，后续模型更新不得影响该订单。

## 7. 推荐技术边界

- 新增独立业务应用，员工端建议路由为 `/gift`，复用现有 `shared-ui` 的 ToolHeader、Logo、语言切换和基础视觉规范；
- 管理端使用独立域名 `ops.unionam.com`，与员工端在访问入口和权限边界上隔离；
- 员工端、管理端和后端 API 使用统一身份体系，但管理端必须采用独立角色权限校验；
- AI 生成采用异步任务队列，避免请求长时间占用浏览器或 Web 进程；
- 模型文件使用对象存储，数据库保存元数据、权限、版本、任务和订单；
- 模型检查服务与 AI 生成服务解耦，便于未来替换模型生成供应商；
- V1 生产流程保留“下载模型后人工打印”的能力，打印机自动下发作为后续阶段。

## 10. 验收标准

- 非联泰账号无法进入礼品业务页面；
- 在职员工登录后可以完整浏览礼品并提交一个已有模型订单；
- 在职员工可以提交一条展会样品或业务样件打印申请，并看到审核、排产和完成状态；
- 员工只能看到自己的订单和自己有权限访问的模型；
- AI 生成任务可以正确显示排队、成功、失败和重试状态；
- 生成模型检查不通过时不能直接进入生产状态；
- 管理员可以审核模型、审核订单并推动生产状态；
- 生产人员只能获取已批准的模型版本；
- 员工可以看到订单状态变化和领取信息；
- 删除或撤销权限后，原会话和文件下载链接不能继续访问；
- 任何后台关键操作都能在审计日志中追溯；
- 移动端和桌面端均能完成登录、浏览、下单和查单；
- 线上部署不影响首页、自动报价和格式转换工具。

## 11. 核心指标

- 企业微信登录成功率；
- 月活跃员工数和首次使用转化率；
- 礼品模型详情访问到下单的转化率；
- 客户礼赠、展会样品、业务样件等不同类型申请量及占比；
- 已有模型复用率和重复建模减少量；
- AI 生成任务成功率、平均耗时和重试率；
- 模型自动检查通过率、人工驳回率；
- 订单批准率、取消率、打印完成率；
- 平均下单到完成时长；
- 生产失败率和重复打印率；
- 员工满意度与热门礼品使用情况。

## 12. 待确认事项

以下事项会影响数据库、权限和流程设计，建议评审时优先确认：

1. 员工是否完全免费，还是需要部门预算/项目号/额度管理？
2. 是否只支持办公地点自取，是否需要内部配送？
3. 是否所有员工都能下单，还是按部门、职级或活动批次开放？
4. AI 生成使用公司内部模型、私有化部署，还是经过审批的第三方服务？
5. 客户图片、客户特征和 Logo 的数据保留周期及禁止上传范围是什么？
6. AI 生成模型是否必须人工审核，哪些礼品类型可以自动放行？
