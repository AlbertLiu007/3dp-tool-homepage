# 联泰礼品站企业微信扫码登录接入说明

## 1. 企业微信后台配置

1. 使用联泰企业微信管理员账号进入管理后台。
2. 在“应用管理 → 自建应用”中创建或选择“联泰礼品站”应用。
3. 将应用可见范围设置为允许使用礼品站的联泰员工。若所有在职员工都可以使用，应覆盖全公司通讯录。
4. 记录企业 ID（CorpID）、应用 AgentId 和应用 Secret。
5. 在该自建应用中开启“企业微信授权登录”。
6. 授权回调域设置为 `unionam.com`。回调域不包含协议和路径，且必须与实际登录域名精确匹配。
7. 如果企业微信后台要求配置企业可信 IP，将生产服务器公网出口 IP `8.153.16.140` 加入可信 IP。

生产回调地址为：

```text
https://unionam.com/api/gift/auth/wecom/callback
```

## 2. 服务端环境变量

参照仓库根目录的 `.env.example` 配置生产环境变量：

```text
WECOM_CORP_ID=
WECOM_AGENT_ID=
WECOM_APP_SECRET=
WECOM_CALLBACK_URL=https://unionam.com/api/gift/auth/wecom/callback
GIFT_SESSION_SECRET=
```

`WECOM_APP_SECRET` 和 `GIFT_SESSION_SECRET` 只能保存在服务器环境变量中，不得提交到 Git、写入前端代码或通过浏览器返回。

会话密钥建议使用以下命令生成：

```bash
openssl rand -base64 48
```

## 3. 当前鉴权流程

1. 员工进入 `/gift`，桌面端由企业微信官方组件在页面内展示真实登录二维码；移动端提供官方授权页入口。
2. 服务端生成一次性随机 `state`，使用 HttpOnly Cookie 保存，用于防止 CSRF。
3. 员工使用手机企业微信扫码并在手机端确认；若内嵌组件无法加载，可通过备用入口进入企业微信官方登录页。
4. 企业微信回调 `/api/gift/auth/wecom/callback`，携带一次性 `code` 和 `state`。
5. 服务端校验 `state`，使用 CorpID 与应用 Secret 换取企业 access token。
6. 服务端使用 `code` 获取企业微信 `UserId`；无法获得 `UserId` 的账号拒绝登录。
7. 服务端读取成员资料，确认成员属于当前企业且状态为“已激活”。禁用、未激活或退出企业的账号拒绝登录。
8. 验证通过后签发 8 小时有效的签名 HttpOnly 会话 Cookie，员工进入礼品站。

## 4. 本地开发说明

企业微信真实扫码登录要求回调域为后台配置的可信 HTTPS 域名，`localhost` 通常不能作为正式回调域。

本地开发环境保留“模拟登录”按钮，但它调用的是仅在非生产环境开放的服务端接口。生产构建中该接口返回 404，页面也不显示模拟登录入口。

正式联调建议使用独立测试域名，例如 `gift-test.unionam.com`，并在企业微信后台配置对应的精确回调域。

## 5. 上线前检查

- 自建应用可见范围覆盖目标员工。
- 授权回调域与实际域名完全一致。
- 服务器可信 IP 已配置。
- 生产环境变量齐全，Secret 未进入 Git。
- 非联泰账号、禁用员工和退出企业员工均无法建立会话。
- 注销后会话 Cookie 被清除。
- 所有礼品订单、模型上传和下载 API 均调用服务端会话校验，不能只依赖前端隐藏页面。
